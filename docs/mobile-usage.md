# Mobile Usage

The MVP is a mobile-friendly browser app served by `script.google.com`.

GitHub is source storage only. GitHub Pages is not used for MVP production. Do not put credentials, private Sheet URLs, private Web App URLs, OAuth tokens, or backup JSON in GitHub.

## iPhone

1. Open the Apps Script `/exec` URL in Safari.
2. Tap `Share`.
3. Tap `Add to Home Screen`.
4. Open the app from the new home screen icon.

## Android

1. Open the Apps Script `/exec` URL in Chrome.
2. Open the browser menu.
3. Tap `Add to Home screen`.
4. Open the app from the new home screen icon.

## Mobile Checks

1. Dashboard cards fit without horizontal page scrolling.
2. Portfolios, positions, holdings, and settings tabs can be reached from the tab bar.
3. Forms can be submitted with the mobile keyboard.
4. Backup export shows JSON in the Settings tab.
5. Import and reset confirmation fields are readable before submitting.

Use `/exec` for normal mobile usage. `/dev` is for Apps Script development testing.
